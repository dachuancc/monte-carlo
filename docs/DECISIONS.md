# 架构决策记录（ADR-lite）— monte-carlo

## D1 用解析解直接模拟 GBM，而非 Euler 离散化

- **决定**：$\;S_{t+\Delta t} = S_t \exp\big((\mu - \tfrac12\sigma^2)\Delta t + \sigma\sqrt{\Delta t}\,Z\big)$。
- **考虑过的其他选项**：
  - *Euler 离散化* —— 会引入**离散化偏差**，且这个偏差会污染后面"MC 是否收敛到 BS"
    的验证：分不清误差来自离散化还是采样。
  → 选解析解直接采样：GBM 本来就有闭式解。
- **影响**：误差只剩采样误差，收敛研究才有意义。多资产扩展时（M5）也照此处理。

## D2 定价一律用风险中性漂移

- **决定**：给期权定价时，模拟漂移取无风险利率 $r$，贴现因子 $e^{-rT}$。
- **考虑过的其他选项**：
  - *用真实收益率 $\mu$ 作漂移* —— 会得到一个"看似合理但错误"的数。
  → 选风险中性漂移 $r$：这是无套利定价的基本结论——期权价格与 $\mu$ 无关。
- **影响**：`mc_european` 内部固定 `drift = (r - σ²/2)T`；`paths.simulate_gbm` 仍保留 `mu`
  参数（做路径演示时用），两者用途不同，勿混。

## D3 对偶变量法：先平均每对，再算标准误

- **决定**：对每对 $(Z, -Z)$ 的贴现收益**先取平均**，得到 i.i.d. 样本，再计算标准误。
- **考虑过的其他选项**：
  - *把 $2N$ 个样本直接当独立样本统计* —— $(Z, -Z)$ 两两**相关**，这样会**低估**标准误，
    让结果显得比实际更可信。
  → 选先配对平均：得到的才是 i.i.d. 样本。
- **影响**：`MCResult.n` 记录的是**路径数**（对偶下 $=2m$），而标准误基于 $m$ 个 i.i.d. 对数。
  这一语义差异有测试与文档锁定。

## D4 不引入 scipy

- **决定**：正态 CDF 用 `math.erf` 实现（`norm_cdf`），Black–Scholes 只用标准库。
- **考虑过的其他选项**：
  - *引入 scipy*（用 `scipy.stats.norm`）—— 本项目只需一个正态分布函数，
    为它引入整棵 scipy 依赖树，成本不成比例。
  → 选 `math.erf` 自实现。
- **影响**：解析解与 MC 的对比完全自包含。若未来需要大量特殊函数（M3 可能需要），再重新评估。

## D5 每个估计必须带标准误

- **决定**：定价函数返回 `MCResult`（含 `price` 与 `stderr`），不返回裸 float。
- **考虑过的其他选项**：
  - *返回裸 float（只给点估计）* —— 蒙特卡洛的输出**本质上是一个带噪声的估计**，
    只给点估计等于隐瞒不确定度，是 MC 报告最常见、也最误导人的做法。
  → 选返回 `MCResult`（含 `price` 与 `stderr`）。
- **影响**：CLI 与 README 都展示标准误与 95% CI；收敛图画出置信带。
