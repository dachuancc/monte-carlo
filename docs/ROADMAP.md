# ROADMAP / 项目进度 — monte-carlo

> 这是本项目的**唯一状态真相**。每次接手先读这里，再看 `docs/DECISIONS.md`。

## 如何接手（Human & AI）

1. 在项目目录下启动 pi：`cd monte-carlo && pi`（pi 自动加载 `AGENTS.md`）。
2. 读本文件 + `docs/DECISIONS.md`。
3. `uv run pytest` 确认 **23 个用例**全绿。
4. 从「下一步」继续。

> ⚠️ 开工前用**新会话**，不要恢复旧会话。

## 目标

一个**展示蒙特卡洛方法论**的小型工具库：

- 把"随机模拟逼近解析解"这件事讲清楚、跑出来、验证对。
- 每个估计都带**不确定度**（标准误 / 置信区间），而非只给点估计。
- 覆盖方差缩减这一"让 MC 变得实用"的关键技术。

**不做**：完整衍生品定价库、校准、实时行情、交易接入。这里只做**教学与验证**。

## 当前状态

**M0 / M1 / M2 已完成**：GBM 路径 + BS 解析解 + MC 定价 + 对偶变量法 + 收敛研究 + CLI + 文档 + CI。

- 测试基线：**23 个用例**。
- 核心结果：MC 收敛到 Black–Scholes，误差落在标准误数倍内；对偶变量法使 SE 降约 25%。
- `scripts/make_readme_assets.py` 生成 README 图表与指标表。

## 下一步

- 从 **M4（控制变量法）** 开始最划算：用 BS 解析解作为控制变量，
  能把标准误再降一个数量级，且能直接和现有的对偶变量法叠加对比。
- **M3 的美式期权**是量化的经典硬骨头（LSM），展示价值最高，但成本也最高。

## 已知限制

- 期权仅欧式、仅单资产、仅 GBM 动态（无跳跃、无随机波动率）。
- 对偶变量法只对单调 payoff 保证降方差（看跌 / 看涨成立）。
- 未做希腊字母（Greeks）；可用有限差分或路径导数扩展。
